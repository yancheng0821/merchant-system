# 阿里云短信模板配置说明

## 📋 当前启用的短信场景

由于阿里云审核限制，**+86号码仅支持验证码短信**。系统配置了以下场景：

---

### 1. 登录验证码 (LOGIN_2FA)  ✅ 已配置

**模板CODE**: `SMS_327736525`

**模板内容**: `您的验证码为：${code}，请勿泄露于他人！`

**变量说明**:
- `code`: 验证码（6位数字）

**状态**: ✅ 已申请并配置

---

### 2. 套餐消费验证 (PACKAGE_VERIFICATION) ✅ 已配置

**模板CODE**: `SMS_327736525`（使用验证码模板）

**模板内容**: `您的验证码为：${code}，请勿泄露于他人！`

**变量说明**:
- `code`: 验证码（6位数字）

**状态**: ✅ 使用验证码模板

---

## ⚠️ 已禁用的场景

由于阿里云审核一直不通过，以下预约相关场景的短信**已被禁用**（仅针对+86号码）：

- ❌ 预约确认通知 (APPOINTMENT_CONFIRMATION)
- ❌ 预约取消通知 (APPOINTMENT_CANCELLATION)
- ❌ 预约完成通知 (APPOINTMENT_COMPLETION)
- ❌ 预约提醒通知 (APPOINTMENT_REMINDER)

**注意**:
- +86号码的预约相关短信将**不会发送**
- 其他国家号码的预约短信仍通过AWS SNS正常发送
- 系统会在日志中记录跳过发送的信息

## 🎯 工作原理

### 短信渠道智能路由

系统会根据手机号和场景自动选择合适的发送渠道：

```
+86号码 + 验证码场景    → 阿里云 SMS (SMS_327736525) ✅
+86号码 + 预约场景      → 跳过发送（阿里云审核限制）⏭️
其他国家号码 + 任何场景  → AWS SNS ✅
```

### 变量映射（验证码场景）

| 英文变量名 | 阿里云变量名 | 说明 | 适用场景 |
|-----------|-------------|------|---------|
| code | code | 验证码 | LOGIN_2FA, PACKAGE_VERIFICATION |

## ⚠️ 注意事项

1. **阿里云仅支持验证码**: 由于审核限制，+86号码只能发送验证码短信

5. **验证码模板通用**: 登录验证码和套餐消费验证码使用同一个模板

## ❓ 常见问题

**Q: 为什么+86号码收不到预约短信？**
A: 由于阿里云审核一直不通过，+86号码的预约短信已被禁用。其他国家号码不受影响。

**Q: 如果客户需要预约短信怎么办？**
A: 建议客户使用邮件通知，或者引导客户使用非+86的国际号码。

**Q: 套餐消费为什么用验证码模板？**
A: 套餐消费需要发送验证码进行安全验证，所以复用了验证码模板。

**Q: 将来阿里云审核通过了怎么修改？**
A: 如果预约模板审核通过，需要：
   1. 在 `application.yml` 中添加预约场景的模板映射
   2. 在 `SmsService.java` 中的 `buildTemplateParamByScene` 方法中添加预约场景的变量映射
   3. 移除或注释 `isAppointmentRelatedScene` 的过滤逻辑
