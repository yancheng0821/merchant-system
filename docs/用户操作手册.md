## 系统简介

Swift Merchant Platform 是一个专业的商户管理系统，集成了订单管理、支付处理、终端管理等核心功能，支持中英文双语操作，帮助商户高效管理日常业务。

### 主要特点
- 🌍 中英文双语支持
- 💳 Stripe支付深度集成
- 📱 支持多种终端设备
- 📊 实时数据分析
- 🔒 安全可靠

## 系统登录

### 1. 首次登录

1. 打开浏览器，访问系统地址
2. 在登录页面输入：
   - **邮箱**：您的注册邮箱
   - **密码**：您的账户密码
3. 选择界面语言（中文/English）
4. 点击「登录」按钮

### 2. 忘记密码

1. 点击登录页面的「忘记密码」链接
2. 输入注册邮箱
3. 查收重置密码邮件
4. 点击邮件中的链接设置新密码

### 3. 语言切换

系统支持随时切换语言：
- 点击右上角的语言切换按钮
- 选择「中文」或「English」
- 系统将自动刷新并显示所选语言

## 订单管理

### 1. 查看订单列表

**步骤：**
1. 点击左侧菜单「订单管理」
2. 系统显示所有订单列表
3. 可查看订单的：
   - 订单号
   - 客户信息
   - 金额
   - 支付状态
   - 创建时间

### 2. 搜索和筛选订单

**搜索功能：**
- 在搜索框输入订单号、客户名称或邮箱
- 按Enter键或点击搜索图标

**筛选选项：**
- **日期范围**：选择开始和结束日期
- **支付状态**：
  - 待支付 (pending)
  - 已支付 (paid)
  - 已退款 (refunded)
  - 已取消 (cancelled)
- **金额范围**：设置最小和最大金额

### 3. 查看订单详情

1. 在订单列表中点击订单行
2. 弹出订单详情窗口，显示：
   - 完整订单信息
   - 商品明细
   - 支付历史
   - 操作日志

### 4. 导出订单

1. 选择需要导出的订单（可多选）
2. 点击「导出」按钮
3. 选择导出格式：
   - Excel (.xlsx)
   - CSV (.csv)
   - PDF

## 支付处理

### 1. 收款操作

**使用终端收款：**
1. 确保终端已连接（终端指示灯为绿色）
2. 在收银界面输入金额
3. 选择支付方式：
   - 💳 信用卡/借记卡
   - 📱 移动支付（Apple Pay/Google Pay）
   - 💵 现金
4. 客户在终端上完成支付
5. 系统自动生成订单和收据

### 2. 退款处理

**发起退款：**
1. 进入「订单管理」
2. 找到需要退款的订单
3. 点击「退款」按钮
4. 在退款对话框中：
   - 选择退款类型：
     - ✅ 全额退款
     - ⚡ 部分退款
   - 如选择部分退款，输入退款金额
   - 选择退款原因：
     - 重复收费
     - 客户要求
     - 商品问题
     - 服务不满意
     - 订单取消
     - 其他
5. 确认退款信息
6. 点击「确认退款」

**退款注意事项：**
- ⚠️ 退款将在1-3个工作日到账
- ⚠️ 部分退款后可再次退款剩余金额
- ⚠️ 全额退款后订单状态变为「已退款」

### 3. 支付对账

1. 进入「报表分析」→「支付对账」
2. 选择对账日期
3. 系统显示：
   - 总收入
   - 退款金额
   - 净收入
   - 各支付方式占比

## 终端管理

### 1. 添加新终端

**前置条件：**
- 已在Stripe账户中注册终端
- 获取终端序列号

**添加步骤：**
1. 进入「系统设置」→「终端管理」
2. 点击「添加终端」按钮
3. 填写终端信息：
   - **终端名称**：如"前台POS"、"收银台1"
   - **位置标签**：选择或创建位置
   - **终端类型**：S700/M2/其他
4. 点击「连接Stripe」
5. 从Stripe终端列表选择对应设备
6. 点击「保存」完成配置

### 2. 管理现有终端

**查看终端状态：**
- 🟢 在线：终端正常连接
- 🟡 离线：终端断开连接
- 🔴 故障：终端需要维护

**终端操作：**
- **重启终端**：解决临时故障
- **更新软件**：保持终端软件最新
- **查看日志**：诊断问题
- **删除终端**：移除不再使用的设备

### 3. 终端故障排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 终端离线 | 网络断开 | 1. 检查WiFi连接<br>2. 重启终端<br>3. 重新配对 |
| 支付失败 | 配置错误 | 1. 检查Stripe设置<br>2. 验证API密钥<br>3. 联系技术支持 |
| 打印机故障 | 缺纸/卡纸 | 1. 补充打印纸<br>2. 清理打印机<br>3. 重启设备 |

## 报表分析

### 1. 销售概览

**查看实时数据：**
1. 进入「数据分析」→「销售概览」
2. 选择时间范围：
   - 今日
   - 本周
   - 本月
   - 自定义范围
3. 查看关键指标：
   - 💰 总销售额
   - 📦 订单数量
   - 👥 客户数量
   - 💵 平均订单金额

### 2. 销售趋势分析

**生成趋势图表：**
1. 选择分析维度：
   - 按时间（日/周/月）
   - 按产品类别
   - 按支付方式
   - 按门店位置
2. 设置对比周期
3. 查看可视化图表：
   - 📈 折线图：趋势变化
   - 📊 柱状图：对比分析
   - 🥧 饼图：占比分布

### 3. 导出报表

1. 在报表页面点击「导出」
2. 选择导出内容：
   - 汇总数据
   - 明细数据
   - 图表截图
3. 选择文件格式
4. 系统生成并下载报表

## 系统设置

### 1. 商户信息设置

**更新商户资料：**
1. 进入「系统设置」→「商户信息」
2. 可修改：
   - 商户名称
   - 联系方式
   - 营业地址
   - 营业时间
   - Logo图片
3. 点击「保存」

### 2. 员工管理

**添加员工账号：**
1. 进入「系统设置」→「员工管理」
2. 点击「添加员工」
3. 填写员工信息：
   - 姓名
   - 邮箱（用于登录）
   - 电话
   - 职位
4. 设置权限（如有权限模块）
5. 点击「创建账号」
6. 系统发送账号激活邮件给员工

**管理员工权限：**
- 查看订单 ✅
- 处理退款 ⚠️（需审批）
- 查看报表 ✅
- 系统设置 ❌（仅管理员）

### 3. 支付设置

**配置Stripe账户：**
1. 进入「系统设置」→「支付设置」
2. 点击「连接Stripe账户」
3. 跳转到Stripe进行授权
4. 完成授权后自动返回
5. 验证连接状态

**设置支付参数：**
- 最小支付金额
- 小费选项（0%/10%/15%/20%）
- 收据打印设置
- 退款审批流程

### 4. 通知设置

**配置通知规则：**
- 📧 邮件通知：
  - 新订单提醒
  - 大额交易提醒
  - 每日销售汇总
- 📱 系统通知：
  - 退款申请
  - 终端离线警告
  - 库存预警

## 常见问题

### Q1: 无法登录系统？
**A:** 请检查：
1. 用户名和密码是否正确
2. 账号是否已激活
3. 浏览器是否禁用了Cookie
4. 尝试清除浏览器缓存

### Q2: 终端显示离线？
**A:** 解决步骤：
1. 检查终端电源和网络连接
2. 在终端上重新连接WiFi
3. 重启终端设备
4. 在系统中重新配对终端

### Q3: 退款失败怎么办？
**A:** 可能原因：
1. 超过退款时限（通常180天）
2. 客户卡片已失效
3. Stripe账户余额不足
4. 联系技术支持处理

### Q4: 如何修改登录密码？
**A:** 步骤：
1. 登录系统后点击右上角头像
2. 选择「个人设置」
3. 点击「修改密码」
4. 输入旧密码和新密码
5. 点击「确认修改」

### Q5: 报表数据不准确？
**A:** 检查：
1. 时区设置是否正确
2. 筛选条件是否准确
3. 是否有未同步的离线数据
4. 尝试刷新页面或重新生成报表

### Q6: 如何联系技术支持？
**A:** 支持渠道：
- 📧 邮箱：support@swiftmerchantplatform.com
- 📞 电话：1-888-XXX-XXXX
- 💬 在线客服：系统右下角对话框
- 🕐 服务时间：周一至周五 9:00-18:00
